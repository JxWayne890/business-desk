## Methods

### Scope reusable motion deliberately

Original research status: supported.

Use appropriate easing and scoped parameters for motion that supports the task. A playful example does not establish a need for animation on every page.

* [The Power (and Fun) of Scope with CSS Custom Properties | CSS-Tricks](https://css-tricks.com/the-power-and-fun-of-scope-with-css-custom-properties/). Author: Jhey Tompkins. Locator: Animation alterations. Use scoped variables to vary a reusable animation instead of duplicating every definition. His playful button is a worked example, not a recommendation to make every client action shake or loop. Recheck modern custom property animation capabilities.
* [Jhey Tompkins, public X teaching 2023-12-07](https://x.com/jh3yy/status/1732553845530566855). Author: Jhey Tompkins. Locator: Root post 1732553845530566855, exact passage in preserved API text. Scoped variables control repeated motion elements in this worked CSS scene. Use the technique only when its motion serves the client journey, with reduced motion and performance checks.

### Test motion in its actual space

Original research status: supported.

Validate animated paths at component and viewport sizes and keep meaningful content available when motion is removed or unsupported.

* [Create a Responsive CSS Motion Path? Sure We Can! | CSS-Tricks](https://css-tricks.com/create-a-responsive-css-motion-path-sure-we-can/). Author: Jhey Tompkins. Locator: Opening explanation of hardcoded motion paths. Test animated paths at actual component and viewport sizes. Fixed path coordinates can make motion leave the intended area. Historical workarounds need current feature checks and an appropriate nonanimated experience.
* [Jhey Tompkins, public X teaching 2023-12-30](https://x.com/jh3yy/status/1740938761909731562). Author: Jhey Tompkins. Locator: Root post 1740938761909731562, exact passage in preserved API text. The responsive marquee teaching explicitly limits animation to people with no reduced motion preference. Keep the useful content available without animation and provide pause controls where required.

### Choose motion timing intentionally

Original research status: candidate.

Prefer appropriate and unobtrusive timing, verify current support, and provide a useful static experience. The published diagram and text do not establish that every linked demo ran correctly.

* [The Path To Awesome CSS Easing With The linear() Function — Smashing Magazine](https://www.smashingmagazine.com/2023/09/path-css-easing-linear-function/). Author: Jhey Tompkins. Locator: Opening motion design explanation. Choose easing and transitions deliberately so motion feels appropriate and unobtrusive. Inspect current support and provide a usable reduced motion experience. The 2023 browser support list is historical.

### Derive layer movement from a common progress value

Original research status: supported.

Use deliberate parameters to coordinate the scene, and progressively enhance a complete base layout. Verify current CSS support or use an appropriate library fallback.

* [Responsive CSS parallax](https://x.com/jh3yy/status/2066545559096205471). Author: Jhey Tompkins. Locator: Author text in post 2066545559096205471. The author describes reused keyframes with container position and calc for responsive parallax. This is a specific CSS example. Check current browser support and retain a complete fallback.
* [A shared progress value drives motion](https://x.com/jh3yy/status/2063083606877126943). Author: Jhey Tompkins. Locator: Author text in post 2063083606877126943. The author drives a custom property with scrolling and derives a sine based translation from it. The example supports coordinated parameters, not a requirement for oscillating client heroes.
