## Methods

### Choose a maintainable stack around user and editorial needs

Original research status: supported.

Evaluate delivery and editorial complexity in the client’s context. Preserve a useful existing platform and editing workflow unless a scoped migration is justified.

* [How I'm Writing CSS in 2024 | Lee Robinson](https://leerob.com/css). Author: Lee Robinson. Locator: User Experience and Developer Experience. Choose maintainable styling tools that improve resource size, caching, layout stability and delivery. Preserve a working client stack unless there is a justified scope decision to change it.
* [Coding Agents & Complexity Budgets | Lee Robinson](https://leerob.com/agents). Author: Lee Robinson. Locator: Removing complexity, context of Cursor site migration. Evaluate editorial workflow and complexity costs before selecting a CMS. His code and Markdown migration fits his team’s context, not every client. Preserve client editing ability, ownership and authorized platform choices.

### Inspect actual metadata and preview behavior

Original research status: supported.

Implement page specific social metadata and inspect fetched tags and rendered previews. A preview simulator does not replace checks of the page response or native platform behavior.

* [Open Graph Preview Tool | Lee Robinson](https://leerob.com/og). Author: Lee Robinson. Locator: Open Graph Preview interface explanation. Inspect actual social metadata and platform preview behavior. This tool description is evidence of practice, not a universal design doctrine or a tested client result.
* [Lee Robinson, public X teaching 2024-04-08](https://x.com/leerob/status/1777327479230783534). Author: Lee Robinson. Locator: Root post 1777327479230783534, exact passage in preserved API text. Root text announces a portfolio template with sitemap and OG features. The template was not executed or audited here. Its existence is limited practice evidence, not a mandated client stack.

### Define roles and restricted actions explicitly

Original research status: candidate.

Map privileged actions, user roles and activity records to actual requirements. Verify authorization on the backend and avoid private data in public responses.

* [Lee Robinson, public X teaching 2024-09-16](https://x.com/leerob/status/1835777934361084316). Author: Lee Robinson. Locator: Root post 1835777934361084316, exact passage in preserved API text. Distinguish owner, member and administrative actions and retain activity records where relevant. Backend authorization and exact framework configuration need current implementation checks.
