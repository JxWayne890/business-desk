# Example prompts

Supply real business facts and source assets when the task depends on them.

## Website plan

```text
Use $business-desk to plan a website for my electrical business. We serve residential customers in the area described in my brief. The main action is a quote request. Use the attached services and approved photos. Recommend the pages and customer journey before implementation.
```

## Website implementation

```text
Use $business-desk to improve this existing website. Keep its current framework and working form integration. Make the service pages easier to understand on a phone. Read the project instructions, implement the changes, and run the relevant build and journey checks.
```

## Facebook post

```text
Use $business-desk to turn these rough notes into a Facebook post in my voice. Keep the actual facts and give readers one clear next step. Prepare the draft only.
```

## Several perspectives

```text
Use $business-desk to review this landing page from website strategy, writing, and sales perspectives. Identify which reference contributes to each recommendation and cite its public sources. Do not pretend the real people discussed my project.
```

## A new expert

```text
Use $business-desk to research [full name] in [field]. Build a personal library from their public professional work, preserve source links, and report what was actually reviewed. Use free accessible sources unless I separately approve a paid collection budget.
```

## Show available references

```text
Use $business-desk to list the bundled reference catalog and any personal research libraries. Explain which ones are most useful for my business and where their evidence has gaps.
```
