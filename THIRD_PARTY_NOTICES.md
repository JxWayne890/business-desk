# Source attribution

The [source index](skills/business-desk/references/experts/sources.json) identifies the original research entries used to prepare this edition.

The license for this repository applies to original package code and writing. It does not grant rights to referenced books, articles, posts, images, videos, trademarks, or private courses. Full source text, bulk social captures, and source images are not distributed.

Names identify the source of teaching. No listed person, company, OpenAI, or GitHub is represented as a sponsor or endorser. Some material has joint authors or company authorship; those distinctions remain in the briefs.

The package's Python code uses the Python standard library. No third party Python library or model is bundled. GitHub Actions used for verification are referenced by version and run only in the repository's automated checks.
