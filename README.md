# Business Desk

**A free Codex skill for agencies, business owners, and client work.**

Business Desk brings researched website, writing, outreach, and business methods into your projects. Describe the job, and it selects relevant source references, checks their coverage, and applies them to your actual business, audience, platform, and scope.

The agency edition includes 46 active expert roles, two supplemental imagery references, nine expert categories, a website workflow covering 24 areas, and a cold outreach workflow. It packages original summaries and source links. It does not include private business records, credentials, or bulk copies of other people’s content.

## What this repository helps with

| Work | What Business Desk helps you produce |
| :--- | :--- |
| Complete client websites | A business brief, customer journeys, page structure, copy, visual direction, and implementation through your available tools. The 24 area workflow covers accessibility, performance, SEO, integrations, testing, and handoff. |
| Website images and motion | Hero image briefs, social previews, image direction, useful diagrams, and purposeful interface animation. Actual generation and rendering need suitable tools. |
| Social writing | Posts shaped around your facts, voice, audience, and platform, with Facebook, LinkedIn, and X adaptations. |
| Cold outreach | Prospect fit, a clear offer, first emails, useful follow ups, reply handling, and campaign diagnosis. Research must support personalization. Sending requires authorization and a connected email tool. |
| Sales and business decisions | Service scope, positioning, offer experiments, discovery, management priorities, cash visibility, and software business questions. Your actual records supply the facts. |
| Research and measurement | Source libraries, citations, evidence gaps, analytics planning, and checks for real user journeys. The optional X helper uses your own account and an explicitly approved collection scope. |

For example, ask Business Desk to plan a dealership site around real inventory, shape a clinic’s appointment journey, review a Shopify product experience, draft social posts for an agency, or improve an email for a specific service and buyer.

See [package contents](docs/CONTENTS.md), the [24 website areas](skills/business-desk/references/guides/website-creation.md), and [example prompts](skills/business-desk/references/examples.md). Hosting, commerce, CRM, email delivery, image generation, and other connected services are supplied separately by your environment.

## Install

You need Codex with local file access. The package is free; your AI access and any optional research service are separate. You do not need an X API account to use the included references and guides. The installer and research helpers use Python 3.9 or newer and its standard library.

1. Download the ZIP above and extract it.
2. Open the extracted `business-desk` folder as a local project in Codex.
3. Paste this request:

```text
Read README.md and inspect install.py. Install Business Desk from this folder using the included Python installer. Then check the installation and show me one useful starting prompt. Preserve any existing installation and use the documented backup process for an update.
```

If you prefer the terminal, run these commands from the extracted folder:

```sh
python3 install.py
python3 install.py --check
```

On Windows, use `py -3` instead of `python3` if that is how Python is installed. No administrator access is needed.

The installer places the complete skill in `~/.agents/skills/business-desk`. Codex documents this as a user skill location. If it does not appear, start a fresh chat or restart Codex. [Official skill documentation](https://learn.chatgpt.com/docs/build-skills)

Then try:

```text
Use $business-desk to plan a website for my business. Start with my customers, what they need to know, and the action I want them to take. Tell me which facts and assets you need from me.
```

More [example prompts](skills/business-desk/references/examples.md) cover website changes, social posts, expert research, and combined reviews.

## Updates

I plan to keep updating Business Desk as I improve my own workflow. Updates will be published as versioned releases here. Use GitHub's Watch menu to follow releases if you want notifications. No automatic updater or recurring collection runs on your computer.

Download and extract the latest release, open its folder, and run:

```sh
python3 install.py --update
python3 install.py --check
```

An existing managed installation is backed up before replacement. The command prints the backup location. Local edits to installed skill files remain in that backup; reapply them deliberately if you want them in the new version.

Your own expert research lives separately in `~/.business-desk/library` by default and is not changed by updates. See [installation help](docs/INSTALL.md) for other locations, backups, and removal.
